#Process
1) Create Tag.
2) Name tag: AL-0001 (eg)
3) Set contact: 0000000000
4) Visit: https://www.qrcode-monkey.com/?utm_source=chatgpt.com
5) Create QR Code for the unique ID created (Save AS PNG)
6) Visit https://convertio.co/
7) Convert file to SVG
